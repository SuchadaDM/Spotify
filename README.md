| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Most Streamed Artists on Spotify |
| แหล่งที่มาเดิม | https://www.kaggle.com/datasets/rishavsvault/most-streamed-artists-on-spotify |
| ประเภทข้อมูล | ข้อมูลสถิติยอดสตรีมของศิลปิน 1 แถวต่อศิลปิน 1 คน (ศิลปินที่มียอดสตรีมสูงสุด 500 อันดับแรก) |

`pd.read_csv("Spotify.csv")`

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `Spotify.csv`

ข้อมูลมีทั้งหมด 500 แถว 14 คอลัมน์ ค่าว่างทุกคอลัมน์ = 0

| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ |
| --- | --- | --- |
| `Artist Name` | ข้อความ | ชื่อศิลปินหรือวง (ไม่ซ้ำกัน 500 รายการ) |
| `Sex` | ข้อความ | เพศของศิลปิน ได้แก่ Male (390), Female (88) และ Mixed (22 ใช้กับวงที่มีสมาชิกหลายเพศ) |
| `Country of Origin` | ข้อความ | ประเทศต้นกำเนิดของศิลปิน มี 43 ประเทศ มากที่สุดคือ United States (265), United Kingdom (55), Mexico (27) |
| `Primary Language` | ข้อความ | ภาษาหลักของเพลง มี 11 ภาษา มากที่สุดคือ English (340), Spanish (105), Portuguese (15) |
| `Primary Genre` | ข้อความ | แนวเพลงหลัก มี 23 แนว มากที่สุดคือ Hip-Hop (115), Pop (102), Rock (60), Reggaeton (43) |
| ` Artist Type` | ข้อความ | ประเภทศิลปิน ได้แก่ Solo (373) และ Group (127) **หมายเหตุ:** ชื่อคอลัมน์ในไฟล์ดิบมีช่องว่างนำหน้า ควรใช้ `df.columns.str.strip()` ก่อนใช้งาน |
| `Debut Year` | ตัวเลข (จำนวนเต็ม) | ปีที่เริ่มเดบิวต์ ช่วง 1939–2023 ค่าเฉลี่ยประมาณ 2005 |
| `Total Streams (in millions)` | ตัวเลข | ยอดสตรีมรวมทั้งหมด หน่วยล้านครั้ง ช่วง 6,972 – 137,492.1 (ค่าเฉลี่ยประมาณ 16,818) เป็นตัวแปรหลักสำหรับการจัดอันดับ |
| `Lead Streams (in millions)` | ตัวเลข | ยอดสตรีมจากเพลงที่ศิลปินเป็นศิลปินหลัก (lead) หน่วยล้านครั้ง |
| `Feature Streams (in millions)` | ตัวเลข | ยอดสตรีมจากเพลงที่ศิลปินร่วมร้อง (feature) ในเพลงของผู้อื่น หน่วยล้านครั้ง |
| `Solo Streams (in millions)` | ตัวเลข | ยอดสตรีมจากเพลงที่ศิลปินร้องคนเดียว หน่วยล้านครั้ง |
| `% of Solo Streams` | ตัวเลข | สัดส่วนยอดสตรีมเดี่ยวต่อยอดรวม หน่วยเป็นเปอร์เซ็นต์ (0–100) |
| `Collaborative Streams (in millions)` | ตัวเลข | ยอดสตรีมจากเพลงที่ร่วมงานกับศิลปินอื่น หน่วยล้านครั้ง |
| `% of Collaborative Streams` | ตัวเลข | สัดส่วนยอดสตรีมร่วมงานต่อยอดรวม หน่วยเป็นเปอร์เซ็นต์ (0–100) |

**หมายเหตุ**
- ยอดสตรีมทุกคอลัมน์มีหน่วยเป็น **ล้านครั้ง** (เช่น 137492.1 = ประมาณ 137,492 ล้านครั้ง)
- `Solo Streams + Collaborative Streams = Total Streams` และ `% of Solo + % of Collaborative = 100` (ตรวจแล้วตรงทุกแถว)
- `Lead Streams + Feature Streams` **ไม่เท่ากับ** `Total Streams` ในหลายแถว (397 จาก 500 แถว) จึงไม่ควรสมมติว่ารวมกันได้ยอดรวม
- ข้อมูลเป็นภาพ ณ เวลาที่ผู้เผยแพร่บน Kaggle รวบรวม ไม่ใช่ข้อมูลเรียลไทม์
